# Robot-Dog-Exploded-View-and-Assembly-Algorithm

## Overview

This project shows the CAD assembly and exploded view of a robot dog in Onshape. The exploded view helps explain how the body, legs, joints, servo motors, and brackets fit together.

## Main Parts

* Main body
* Four legs
* Servo motors
* Motor brackets
* Joints
* Screws and fasteners

## Assembly Steps

1. Import all parts into an Onshape Assembly.
2. Fix the main body.
3. Add the servo motors and brackets.
4. Connect the upper and lower leg parts.
5. Add revolute mates to the joints.
6. Repeat for all four legs.
7. Check movement and collisions.
8. Create the exploded view.

## Exploded View

The exploded view separates the parts to clearly show their positions and connections.
